Tanks — mockups

Three vendors × two accounts, every allowance window as a horizontal tank. Solid = used so far; hatched = projected further use by the reset at the current burn rate; a red tick at the right edge = the projection crosses 100% before the reset. Blue bar = the account that is not signed in right now (its numbers still update).

Reading order is fixed: the advice strip first (what to do), then vendors top to bottom in the order you use them, active account always in the left column. Every number the advisor quotes is visible in the bars below it, so a recommendation can be checked in one glance.
The "switch" link on the inactive Claude column runs acc admin (Touch ID, existing tool). Codex switching swaps the CLI's auth file the same way. Cursor has no supported account swap, so its column says "manual" and the advice tells you when it is worth doing.

The attention state is the same panel with the top recommendation promoted and coloured. The switch button runs the existing acc flow; the app does not hold the Touch ID gate itself. Once the switch completes the app re-polls both accounts and the strip returns to normal.
Second-line advice is time-shifted: it names the future hour a weekly window will bind, so it can be answered with a reminder instead of an action now.
